# Zig 0.16 or later only

`build.zig.zon` already has `minimum_zig_version = "0.16.0"`.

## What changed

| 0.14 / early 0.15 | 0.16+ |
|-------------------|-------|
| `pub fn main() !void` | `pub fn main(init: std.process.Init) !void` |
| `std.net.Address.listen` + `stream.read` / `stream.writer()` | `std.Io.net.IpAddress` + `stream.reader(io, buf)` / `writer(io, buf)` |
| `readFileAlloc(alloc, path, max)` | `readFileAlloc(path, alloc, .limited(max))` |
| `@cImport({ @cInclude("sqlite3.h"); })` | `extern fn sqlite3_*` in `db.zig` |
| `verifyPassword(a, undefined, ...)` | `verifyPassword(a, init.io, ...)` |

JSON in `std.fmt`: `\"` for quotes, `{{` / `}}` for braces, `{s}` `{d}` for slots.

## Build

```bash
zig version   # must be 0.16.0 or newer
cd ~/MagiMDM && git pull && zig build && ./zig-out/bin/zig-mdm
```

If a symbol moved after 0.16.0 (Io.net is still shifting), paste the first compiler error.
